# 🌍 SmartTools Converter

SmartTools Converter is a lightweight, all-in-one web app for real-time **currency conversion** and **unit conversion**.  
It’s optimized for performance and can be deployed instantly on **Vercel**.

---

## 🚀 Features
- ✅ Real-time currency conversion using [exchangerate.host](https://exchangerate.host)
- ✅ Unit conversion (length, weight, temperature, speed, area, volume, time, data, energy)
- ✅ Currency flags & intuitive dropdowns
- ✅ Historical charts (7/30/90 days) powered by Chart.js
- ✅ Responsive & mobile-friendly UI
- ✅ Works offline for unit conversions
- ✅ Fast deployment on Vercel or GitHub Pages
